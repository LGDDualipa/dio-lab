# Desafio de Investimento no Excel
## Visão Geral

Esta planilha foi desenvolvida para simular e projetar investimentos de forma prática e automatizada. O cliente insere o valor do aporte inicial e, a partir disso, são calculados automaticamente:

- Rendimentos mensais
- Rendimentos anualizados
- Projeções por tipo de investimento
- Comparações entre diferentes estratégias

## Funcionalidades

- Entrada de aporte inicial personalizada
- Cálculo automático de rentabilidade com base em parâmetros definidos
- Simulação de diferentes tipos de investimento (renda fixa, variável, fundos, etc.)
- Visualização clara dos resultados em tabelas e gráficos
- Espaço para ajustes de taxas, prazos e metas
